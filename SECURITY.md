# Security policy

## Supported versions

Security fixes are currently considered for the latest code on the `main` branch. There are no maintained release branches or versioned releases.

## Reporting a vulnerability

Please do not report security vulnerabilities in public issues or discussions. Use GitHub's **Report a vulnerability** action for this repository to send a private report. If that option is unavailable, contact the repository maintainers through the contact details on the repository owner's GitHub profile and ask for a private security reporting channel.

Include the affected component and commit or version, a description of the impact, and steps to reproduce using synthetic data. Do not attach real consumer records, evidence, credentials, access tokens, or other personal data.

Maintainers will acknowledge reports when practical, assess their impact, and coordinate a fix and disclosure with the reporter. There is no guaranteed response or remediation timeframe.

## Current scope

Aduen is a local-first prototype and synthetic-data API foundation. It is not approved for real consumer records. Please report vulnerabilities affecting the repository's code, build, or documented deployment artifacts; do not send production data as part of a report.
