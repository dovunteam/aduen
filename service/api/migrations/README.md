# Case API database migration

Run `npm run build` then `DATABASE_URL_MIGRATOR=... npm run migrate` from this directory. The migration role must own the schema and must be able to grant table privileges to the pre-created, non-superuser `aduen_api` and `aduen_retention` roles. The API itself must use `DATABASE_URL` for the restricted runtime role.

Migration 001 enables and forces PostgreSQL row-level security on case and audit tables. Migration 002 adds an audit-retention policy and index. Migration 003 adds shared API rate-limit buckets. Client keys are HMAC-SHA256 digests; the API role increments counters and deletes expired buckets, while `aduen_retention` can see only expired buckets' timestamps and delete those rows. It cannot read their keys or counts. Migration 004 adds inactivity retention for hosted cases. The retention role can see only `updated_at` for eligible cases and delete those rows; it cannot read case content, owners, or IDs. For audit events it can read only timestamps and delete rows older than a transaction-local cutoff; it cannot read audit subjects, case IDs, or actions. The API starts a transaction and sets `aduen.user_sub` locally for each request. Never run the API as a table owner or superuser; PostgreSQL bypasses row policies for superusers.

Run the expiry command using `DATABASE_URL_MAINTENANCE` and an explicitly selected `AUDIT_RETENTION_DAYS` value from 1 to 3650. Schedule it with the deployment's job runner only after security and privacy reviewers approve the audit schedule. The repository does not select a production retention period or deployment cadence.

Run hosted-case expiry using the same restricted maintenance role and an explicitly selected `HOSTED_CASE_RETENTION_DAYS` value from 1 to 3650. It deletes records based on server-controlled `updated_at`, so each accepted edit resets inactivity age. Select the period and job cadence only after security and privacy review. The API refuses production startup until a valid period is configured; the Compose maintenance job is `prune-hosted-cases`.
